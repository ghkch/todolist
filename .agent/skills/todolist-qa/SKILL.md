# TodoList QA 검증 스킬

## 1. 자동화 검증 명령
- 타입 검사: `npm run typecheck`
- 린트 검사: `npm run lint`
- 단위·통합 테스트: `npm run test`
- 프로덕션 빌드: `npm run build`

## 2. 필수 기능 검증 시나리오
- 할 일 추가, 앞뒤 공백 제거, 빈/공백 입력 오류, 200자 제한, 한글 IME 조합 중 Enter 무시
- 완료/미완료 토글 및 시각적 구분(색상 + 취소선 + 체크 표시)
- 내용 수정 저장(Enter/버튼), 취소(Esc/버튼), 빈 내용 저장 차단, 포커스 복귀
- 개별 삭제 및 실행 취소(원래 데이터와 위치 복원), 연속 삭제 시 최신 1건 복원
- 상태 필터(전체/진행 중/완료)와 검색 교집합, 결과 없음 vs 전체 비어 있음 구분, 검색어 초기화
- 완료 항목 일괄 삭제(0개 시 비활성화, 확인 대화상자 개수 표시, 취소 시 데이터 유지)
- 새로고침 후 복원, 손상된 JSON 보호, 상위 버전 보호, localStorage 쓰기 실패 시 메모리 동작

## 3. 반응형 및 접근성 브라우저 검증
- 뷰포트: `360px`(모바일), `768px`(태블릿), `1440px`(데스크톱)
- 긴 한국어 문장 및 공백 없는 긴 문자열(예: URL/연속 문자)에서 가로 스크롤 없음 확인
- 키보드 Tab 탐색 순서, `:focus-visible` 링 가시성, 삭제 후 포커스 이동 확인
- `prefers-reduced-motion: reduce` 적용 확인
- 브라우저 콘솔 에러/경고 0건 확인

# 나의 할 일 — 한국어 개인용 TodoList 웹앱

하루의 할 일을 빠르게 추가하고, 완료하고, 정리할 수 있는 파스텔톤 미니멀 TodoList 웹앱입니다.
어린이와 노인도 쉽게 사용할 수 있도록 넉넉한 버튼 크기(44~48px), 명확한 한글 레이블, 높은 텍스트 대비, 단순한 화면 구조를 적용했습니다.

## 주요 기능

1. **할 일 추가**
   - `Enter` 또는 **추가** 버튼으로 등록하며 앞뒤 공백을 자동 제거합니다.
   - 빈 입력·공백만 있는 입력을 차단하고 오류 안내를 표시합니다.
   - 최대 200자 제한과 글자 수 카운터를 제공합니다.
   - 한글 IME 조합 중 `Enter`로 의도치 않게 등록되지 않도록 처리했습니다.
   - 등록 후 입력창을 비우고 포커스를 유지하며, 최신 항목을 맨 위에 표시합니다.

2. **완료 상태 변경**
   - 체크박스 또는 할 일 문구를 눌러 완료/미완료 상태를 전환합니다.
   - 완료된 항목은 취소선, 보조 색상, 완료됨 배지로 명확히 구분하며 목록 순서는 유지합니다.

3. **내용 수정**
   - **수정** 버튼으로 편집 모드를 시작하고 `Enter` 또는 **저장**으로 반영, `Esc` 또는 **취소**로 되돌립니다.
   - 빈 내용 저장을 차단하고 한글 IME 조합 중 `Enter`를 안전하게 처리합니다.
   - 저장·취소 후 해당 항목의 **수정** 버튼으로 포커스가 복귀합니다.

4. **개별 삭제 및 실행 취소**
   - 삭제 직후 하단 알림의 **실행 취소**로 원래 데이터와 정렬 위치를 복원합니다.
   - 연속 삭제 시 **최신 삭제 1건**만 실행 취소 대상으로 유지됩니다.
   - 삭제 후 포커스가 사라지지 않도록 다음 항목 → 이전 항목 → 입력창 순으로 이동합니다.

5. **상태 필터와 검색**
   - **전체 / 진행 중 / 완료** 필터(`aria-pressed`)와 **할 일 검색**을 교집합으로 적용합니다.
   - 검색어 초기화 버튼과 상태별 빈 화면(목록 비어 있음 / 검색 결과 없음 / 필터 조건 결과 없음)을 구분해 안내합니다.

6. **완료 항목 일괄 삭제**
   - 완료 항목이 없으면 버튼이 비활성화됩니다.
   - native `<dialog>` 확인 대화상자에서 삭제 대상 개수를 안내하며, 취소 시 데이터를 유지합니다.

7. **현황 표시**
   - 전체 수, 완료 수, 남은 수와 완료율 진행 막대를 표시하며 항목이 0개일 때 `0%`로 안전하게 처리합니다.

8. **로컬 자동 저장 및 오류 보호**
   - `localStorage` 키 `todo-app:v1`에 `{ schemaVersion: 1, tasks: [...] }` 형식으로 자동 저장합니다.
   - JSON 파싱 실패, 잘못된 구조, 중복 ID, 지원하지 않는 상위 스키마 버전 감지 시 기존 데이터를 자동 덮어쓰지 않고 내보내기·확인 후 초기화 경로를 제공합니다.
   - `localStorage` 접근·저장 실패 시에도 메모리 상태로 앱을 계속 사용할 수 있으며, 성공 문구 대신 저장 실패 안내와 재시도 버튼을 표시합니다.

## 실행, 빌드 및 테스트 명령

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

### 프로덕션 빌드 및 미리보기
```bash
npm run build
npm run preview
```

### 타입 검사, 린트 및 자동화 테스트
```bash
npm run typecheck
npm run lint
npm run test
```

> **Windows PowerShell 참고**: 실행 정책에 따라 `npm` 대신 `npm.cmd`를 사용해야 할 수 있습니다.

## 저장 방식과 제한사항

- **저장 범위**: 현재 사용 중인 브라우저의 `localStorage`에만 저장됩니다.
- **동기화 및 백업 없음**: 로그인, 계정 동기화, 클라우드 백업, 다른 기기·브라우저 간 데이터 공유 기능은 제공하지 않습니다.
- **데이터 삭제 주의**: 브라우저의 사이트 데이터나 캐시를 삭제하거나 시크릿(프라이빗) 모드를 종료하면 저장된 할 일이 사라질 수 있습니다.
- **다중 탭 제한**: 여러 브라우저 탭에서 동시에 목록을 수정할 때의 충돌 자동 병합은 지원하지 않습니다.
- **실행 취소 범위**: 개별 삭제 실행 취소는 가장 최근에 삭제한 1건만 복원할 수 있으며, 완료 항목 일괄 삭제는 되돌릴 수 없습니다.

## 기술 스택

- React 19 + TypeScript + Vite
- CSS Custom Properties (`DESIGN.md` 기반 단일 디자인 토큰)
- Vitest + React Testing Library + jsdom
- ESLint (TypeScript + React Hooks)
